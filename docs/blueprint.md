# **App Name**: فراد

## Core Features:

- Dashboard Overview: Presents key metrics and insights at a glance, including total personnel count, new additions, those on duty, and those on leave. Also incorporates the LLM tool to analyze overall personnel wellbeing. It also highlights important alerts.
- Personnel Search and Filtering: Allows users to quickly find personnel based on name, national ID, rank, or status, enabling efficient management and reporting. Includes LLM tool which makes fuzzy matches for personnel name.
- Quick Actions: Provides shortcuts to common tasks such as adding new personnel, generating monthly reports, performing backups, and accessing settings, streamlining workflows.
- Add New Personnel: Enables administrators to easily add new personnel records with required information such as full name, national ID, rank, unit, date of appointment, and status.
- Personnel List: Displays a comprehensive list of all personnel with key details, including national ID, name, rank, unit, and status, facilitating quick access and management.
- Activity Feed: Displays new personel additions and promotions.
- Reports & Statistics: Allows the creation of detailed personel reports and statistics

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a sense of trust and authority, aligning with the application's purpose.
- Background color: Light gray (#F9FAFB) to maintain a clean, professional look; also using dark gray (#1F2937) for dark mode.
- Accent color: Teal (#14B8A6) as a contrasting accent to draw attention to interactive elements.
- Body and headline font: 'Tajawal' (sans-serif) for a modern and readable Arabic text.
- Feather Icons for a consistent, clean, and minimalist design.
- Employs a card-based layout with neumorphism design elements for a modern, tactile feel. Consistent use of spacing and alignment to enhance readability.
- Subtle transitions and animations for UI elements. Fade-in effects for content loading to enhance the user experience.
